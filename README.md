# DEMO COIN 샘플 사이트 (landing01 / admin01) — 설치 안내

## 이게 뭔가요
방문자가 마이코인소프트가 만드는 "코인 홈페이지"를 실제로 체험해볼 수 있는 샘플입니다.
- `landing01/` — 방문자가 가입하고 지갑/입출금/추천인을 체험하는 사용자 페이지
- `admin01/` — 그 데이터를 실시간으로 확인하고 승인/거절하는 관리자 페이지 (로그인 없이 공개)

기존 `mycoinsoft.com`의 진짜 관리자 페이지(`admin.html`)와는 완전히 분리된, 별도의 Supabase 테이블을 씁니다.

## 1) 파일 배치
이 폴더(`landing01/`, `admin01/`, `supabase/demo-schema.sql`)를 기존 mycoinsoft 저장소의 **루트**에 그대로 복사해 넣으세요. 기존 `index.html`, `css/`, `js/`, `admin.html` 등과 같은 위치에 있어야 합니다. (landing01/admin01은 내부적으로 `../js/supabase-config.js`, `../index.html` 를 참조합니다.)

```
mycoinsoft/
├─ index.html
├─ admin.html
├─ css/  js/  assets/
├─ landing01/      ← 새로 추가
├─ admin01/         ← 새로 추가
└─ supabase/
   ├─ schema.sql          (기존)
   └─ demo-schema.sql      ← 새로 추가
```

## 2) Supabase 테이블 생성
1. Supabase 대시보드 → **SQL Editor**
2. `supabase/demo-schema.sql` 내용 전체 복사 → 붙여넣기 → **Run**
3. `demo_users`, `demo_transactions`, `demo_notices` 테이블 3개가 생성됩니다. 기존 사이트 Supabase 프로젝트를 그대로 쓰기 때문에 `js/supabase-config.js` 를 다시 설정할 필요는 없습니다.

## 3) 접속 주소
배포 후:
- 사용자 체험 페이지: `https://mycoinsoft.com/landing01/`
- 관리자 체험 페이지: `https://mycoinsoft.com/admin01/`

## 4) 중요 — 보안 관련 안내
요청하신 대로 **관리자 페이지(admin01)를 로그인 없이 완전히 공개**했습니다. 그리고 landing01의 회원가입도 이메일 인증 같은 실제 보안 절차 없이 "아이디 + 4자리 PIN"만으로 동작하는 **데모 전용 간이 로그인**입니다.

그래서 기술적으로는 아래가 가능합니다 (실제 서비스라면 문제지만, "누구나 보고 만져볼 수 있는 쇼케이스"가 목적이라 의도적으로 이렇게 열어뒀습니다):
- 누구나 다른 사람의 잔액을 admin01에서 직접 수정 가능
- 실제 이메일/비밀번호가 아니므로 개인정보 위험은 없음 (가입 시 아이디와 4자리 PIN만 수집)

**즉, 이 데모에는 절대 실제 이름·이메일·전화번호 등 진짜 개인정보를 입력하지 않도록 페이지 안내 문구를 넣어뒀습니다.** 실제 자산도 아니고 실제 개인정보도 다루지 않는, 순수 UI 체험용이라는 점이 명확하면 지금 구조로 충분합니다.

## 5) 데이터 초기화
- **회원 개인 초기화**: landing01에 로그인한 회원이 "내 데모 초기화" 버튼을 누르면 본인 잔액이 100만원으로 리셋되고 본인 신청 내역이 삭제됩니다.
- **전체 초기화**: admin01 하단의 "전체 초기화" 버튼을 누르면 모든 회원과 신청 내역이 삭제됩니다 (공지사항은 유지). 데모가 지저분해졌을 때 관리자가 눌러서 깨끗하게 리셋하는 용도입니다.

## 6) 검색엔진 노출 안 되게 처리
`landing01`, `admin01` 모두 `<meta name="robots" content="noindex, nofollow">` 를 넣어서 구글 검색에는 노출되지 않도록 했습니다. 마이코인소프트 홈페이지 어딘가에 "샘플 체험하기" 버튼으로 링크만 걸어두시면 됩니다 (원하시면 이 작업도 도와드릴게요).

## 7) 추가로 원하시면 알려주세요
- 홈페이지(`index.html`)에 "샘플 체험하기" 버튼/섹션 추가
- 코인 시세 표시, 차트 등 더 화려한 데모 요소 추가
- 회원 로그인 방식을 더 그럴듯하게(예: 이메일 형식) 바꾸기
